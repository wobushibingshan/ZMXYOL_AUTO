# 每日自动化

ZMXYOL_AUTO 把日常任务收成一套可直接跑的预设。完整的「能做什么 / 怎么用 / 功能与文件对照」见仓库根目录 [README](../../../README.md)。

## 推荐用法

1. 用 MFA 客户端打开本项目（开发时加载 `assets/interface.json`，发版后加载安装目录下的 `interface.json`）
2. 连接模拟器，确认短边分辨率是 720
3. 在 **游戏渠道** 中选择与安装包一致的渠道；默认是腾讯应用宝 `com.tencent.tmgp.zmxyol`
4. 选择预设：
   - **一键日常**：启动游戏 → 全部日常 → 关闭游戏
   - **游戏内日常**：已经在村庄时使用，不启停客户端
   - **仅启动到村庄**：只负责启动并关掉公告/活动弹窗

## 日常顺序

| 顺序 | 任务 | 入口要求 |
| --- | --- | --- |
| 1 | 启动游戏 | 模拟器已安装对应渠道包 |
| 2 | 冰霜遗迹 | 村庄世界地图 |
| 3 | 一键碾压 | 村庄世界地图 |
| 4 | 仙盟建设 | 村庄世界地图 |
| 5 | 关卡扫荡 | 可进入天庭 |
| 6 | 联盟 | 村庄世界地图 |
| 7 | 法相挖宝 | 村庄世界地图 |
| 8 | 关闭游戏 | 与启动时相同的包名 |

联盟默认勾选「魔窟探险 / 炼妖塔 / 联盟任务」。关卡扫荡默认勾选「五庄观 / 龙门福地 / 虚空之境 / 八仙过海 / 龙宫」。可在任务选项里取消不需要的项。

## 多角色

「切换角色」是独立任务，不会放进一键日常。一套日常结束后，可手动勾选「切换角色」，再跑一遍「游戏内日常」。
